## 規則與別名範圍

- 支援臺中／台中／中火、完整電廠名稱、全形數字、全形日期斜線、中文機號與中二機／林三機／大二機等原始資料名稱。
- 支援出力不是零、不等於 0、不為 0、大於零，以及出力為零、等於 0、無出力等問法；日期清單與天數分開回傳。
- 支援「由大到小」「最高的兩名」及正出力／零出力篩選與排行的組合。
- 機號完整比對：#100 不會命中 #10；機組後接年份不會將年份併入機號。
- 興達三號機未指定口徑時仍需釐清；指定「興達燃煤第三號機」才查燃煤單機，指定「興達複循環彙總」才查彙總。
- 大潭／通霄必須明確說明彙總；指定其單機時不以彙總值冒充。僅對目前資料中存在的名稱解析，沒有加入模糊相似度猜測。

若要擴充：先以資料定義確認問意與答案，新增題目並觀察測試失敗，再修改規則。測試應保留新日期、新機組與否定句，避免只記住固定題目。成功的網頁查詢仍依原有流程進行語料檢查與人工審查。

```powershell

python -m pytest -q --basetemp logs/qa-all-check
```
